# PSY FAMILY — Complete Overview

> The PSY family is a collection of psytrance music production tools,
> from the original engine to the ultimate standalone instrument.

## Family Members

### PSY6-ULTIMATE (Active)
**The unified endpoint of the PSY device family.**
- One file. Zero server. Infinite groove.
- 150+ features, 53 keyboard shortcuts
- Pattern Banks, Song Arrangement, MIDI Export/Import
- HQ WAV Export, Sound Quality Enhancements
- Live: https://dudududi144-source.github.io/PSY6-ULTIMATE/

### psysynth (Active)
**PSY Synth Device — the canonical subtractive-synth realization device.**
- Pure Web-Audio synthesis
- MIDI-capable, deterministic
- PsyDevice-conformant
- 124 tests passing

### psydrum (Active)
**PSY Drum — Drum device for the PSY family.**
- PsyDevice-conformant
- Pooled voice architecture

### PsySynthPro (Active)
**PsySynthPro — real DSP psychedelic synthesizer in the browser.**
- PolyBLEP + wavetable
- ZDF SVF, FM
- MIDI/MPE, arpeggiator, step sequencer
- WAV export, offline PWA

### psy4 (Active)
**PSY LIVE — Smart radio-following psytrance engine with learning.**
- 137.5 MB, 75 files
- Radio-following engine
- Learning system

### psy-foundation (Active)
**PSY Foundation — Next.js foundation layer for the PSY family.**
- Shared types, utilities, and infrastructure
- 63.3 MB

### psy-sampler
**PSY Sampler Device — canonical family member implementing PsyDevice.**
- Consumes MusicalEvent/Transport/Context from psy-foundation
- Renders sample-based audio via pooled voice architecture

### psy5
**PSY5 — Live Psytrance Performance Instrument.**
- Pooled Engine, No GC Dropouts
- Factory Presets (Psytrance / Techno / Trance / Progressive)

### psy3-clean
**PSY3 Clean — Clean base with critical fixes.**
- Groovebox UI foundation

### psy
**PSY — Original psytrance engine.**
- The beginning of the family

### psy4new (Consider merging)
**PSY4 New — Experimental version of PSY LIVE.**
- 125.4 MB
- Consider merging with psy4

### psysampler (Consider removing)
**PSY Sampler — Sampler device for the PSY family.**
